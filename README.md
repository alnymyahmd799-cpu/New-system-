# تطبيق الويب — البركة للتوزيع

## بنية الملفات

| المسار | المسؤولية |
|---|---|
| `index.html` | الهيكل الدلالي للواجهة والحوار الخاص بالطلب الجديد. |
| `styles.css` | الهوية البصرية والتجاوب وتخطيطات لوحة الإدارة. |
| `js/app.js` | التنقل، الأحداث، وتدفق إنشاء الطلبات. |
| `js/data.js` | النموذج المحلي والحسابات وتخزين المتصفح. |
| `js/firebase-config.js` | إعداد مشروع Firebase ومسار بيانات الويب. |
| `js/firebase-service.js` | القراءة والكتابة الفورية مع Firebase Realtime Database. |
| `js/print-service.js` | إنشاء فاتورة HTML للطباعة أو المشاركة من المتصفح. |
| `js/ui.js` | قوالب العرض المنفصلة للوحة اليوم والطلبات والتقارير والإدارة والإعدادات. |

## ملاحظات التحقق

تحتوي هذه النسخة على ملفات التطبيق الأصلي مباشرة: `index.html` و`style.css` و`app.js` و`firebase-config.js`. لذلك تقرأ البيانات من مسارات Firebase الأصلية مثل `shops` و`orders` و`reps` و`juiceTypes` و`cakeTypes` و`otherTypes`، بدلاً من إنشاء مسار بيانات جديد. تم تحسين طباعة الفاتورة لتستخدم حجماً أساسياً 14px.
